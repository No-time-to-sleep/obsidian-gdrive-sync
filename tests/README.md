# tests

План тестирования (детали — в `docs/ARCHITECTURE.md`, раздел 12):

- Unit: таблица решений синхронизации, конфликтные имена, нормализация путей, игноры, миграции state.
- Contract: Drive adapter против мок-API (пагинация, retry, ошибки квоты, 401/refresh).
- Интеграционные ручные: тестовый Google-аккаунт, сценарии конфликтов и удалений.
- Матрица устройств: Windows, macOS 13+, iPhone.

Тестовый фреймворк: Vitest. Тесты не должны ходить в сеть; Google API — через моки.

Тестов пока нет: на этапе 01 реализована только заглушка плагина.
