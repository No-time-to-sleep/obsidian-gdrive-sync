# План проекта

Формат версий: `vR.SS.TT` (релиз.стадия.подстадия). Одна версия — один завершённый подэтап.
Semver в `manifest.json`: `vR.SS.TT` → `R.SS.TT` без ведущих нулей (например, `v0.02.01` = `0.2.1`).

## Roadmap

### Этап 01. Research & Foundation

- `v0.01.01` — сравнение существующих решений и рынка. ✅ 2026-10-19
- `v0.01.02` — архитектура, OAuth-модель, алгоритм синхронизации. ✅ 2026-10-19
- `v0.01.03` — каркас сборки плагина и контекст проекта. ✅ 2026-10-19 (build + 5 тестов, ручная проверка в Obsidian не выполнялась)

### Этап 02. Auth

- `v0.02.01` — device flow: получение кода, polling, сохранение токенов, обновление access token. ✅ 2026-10-19 (сборка + 30 тестов; живой Google Cloud не проверен)
- `v0.02.02` — UI подключения в настройках (connect / disconnect / статус), проверка на Windows и iOS. 🔄 код готов, ждёт проверки на устройствах
- `v0.02.03` — опциональный desktop loopback + PKCE (отдельный OAuth client type «Desktop app»).

### Этап 03. Drive Adapter

- `v0.03.01` — листинг папки синхронизации и метаданных (полный скан страницами).
- `v0.03.02` — upload/download файлов, создание папок, `trashed=true` вместо удаления.
- `v0.03.03` — retry/backoff, rate limit, обработка дубликатов имён, лимиты размера.

### Этап 04. Sync Engine

- `v0.04.01` — state-модель, база синхронизации, полный первичный скан.
- `v0.04.02` — three-way diff, конфликты, conflict copy.
- `v0.04.03` — удаления, переименования, folder mapping, crash safety.

### Этап 05. Mobile Hardening

- `v0.05.01` — оптимизация памяти и лимиты файлов для iOS.
- `v0.05.02` — поведение при сворачивании приложения, sync on foreground, отсутствие фоновых гарантий.

### Этап 06. UX & Polish

- `v0.06.01` — мастер настройки (пошаговая инструкция по Google Cloud в UI).
- `v0.06.02` — статус-бар, история операций, диагностический лог, «что изменилось».
- `v0.06.03` — исключения по путям, настройки расписания, sync on save.

### Этап 07. Testing & Release

- `v0.07.01` — unit-тесты движка на моках Drive.
- `v0.07.02` — ручная матрица: Windows + macOS (старый) + iOS, сценарии конфликтов и удалений.
- `v0.07.03` — публикация в community plugins, README, privacy policy, финальное имя и id.

## Открытые вопросы (влияют на план)

- Поддерживает ли Changes API scope `drive.file` (влияет на дешёвое инкрементальное сканирование).
- Как ведёт себя `window.open` в Obsidian mobile при открытии Google-верификации (системный браузер или встроенный webview).
- Точная версия Obsidian на всех устройствах (macOS уточнён: 13+) — определяет `minAppVersion`.
- Допустимость device flow на iPhone с точки зрения политики Google (scope допустим, но flow позиционируется для limited-input устройств).
- Финальное имя и id плагина: в магазине уже много плагинов с «Google Drive» и «DriveSync».
