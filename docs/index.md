# GDrive BYO Sync

Two-way Google Drive sync for Obsidian, using **your own** Google Cloud OAuth client (bring your own credentials). No author-hosted servers, no subscriptions, no telemetry.

## Status

Authentication (Google OAuth device flow) is implemented. Drive synchronization is under development. The plugin targets Windows, macOS 13+, and iOS.
