# src

Планируемая структура модулей (появится по мере реализации этапов 02–04):

- `main.ts` — заглушка плагина на этапе 01; далее точка входа, команды, статус-бар.
- `settings.ts` — схема настроек и вкладка настроек.
- `auth/` — device flow, хранение и обновление токенов, revoke.
- `drive/` — Drive API клиент через `requestUrl`, метаданные, upload/download, retry.
- `sync/` — state, сканер, diff, операции, конфликты, очередь.
- `local/` — работа с vault, события, игноры, хеширование.
- `shared/` — типы, ошибки, утилиты, лог.

Правила:

- Runtime-код не использует Node API.
- Целевой ES2018.
- Вся логика, которую можно проверить без Obsidian, выносится в чистые функции и тестируется в `tests/`.
